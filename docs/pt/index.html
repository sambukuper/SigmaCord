channel-list variant=tree {

Fala com o gateway de verdade. É um cliente de verdade.

  1. Tela dividida

    Até três conversas lado a lado, cada uma com o histórico e a rolagem dela. A caixa de texto segue o painel em foco.

  2. Threads e fóruns

    As threads ficam abaixo do canal e abrem como qualquer conversa, com abas, rascunho e busca. Os fóruns mostram a lista de posts no lugar da conversa, com tags e “Novo post”.

  3. Emoji e autocompletar

    Emoji personalizado e figurinhas aparecem como imagem, animados inclusive. O seletor tem a lista Unicode inteira e os emojis dos seus servidores. Na caixa de texto, @, #, :ab e / abrem uma lista.

  4. Leitura sincronizada

    Não lidos e menções batem com o Discord ao abrir o app, e ler em outro aparelho limpa aqui. O canal abre na primeira não lida. As fixadas ficam no alfinete, e links do Discord abrem no app.

  5. Caixa de entrada

    Ctrl+I: DMs e menções não lidas de todos os servidores, por canal, com prévia e “marcar tudo como lido”.

  6. Busca offline

    Ctrl+F busca na memória e no cache local a cada tecla, sem internet. Filtros: from:, in:, has:link, has:imagem, has:arquivo.

  7. Paleta de comandos

    Ctrl+K: busca aproximada de canais, DMs, servidores, temas, status e todas as opções. Esta página também tem uma. Experimente.

  8. Vídeo na conversa

    Anexos e links diretos tocam no lugar, com o FFmpeg do sistema, carregado só no primeiro play. Até 480p e cerca de 30 qps. Sem FFmpeg, o vídeo abre no navegador.

  9. Código que parece código

    Markdown do Discord, interpretado uma vez quando a mensagem chega. Blocos de código têm realce nas cores do tema e botão de copiar, e uma prévia aparece acima da caixa enquanto você digita.

  10. Perfis completos

    Banner, bio, atividade, amigos e servidores em comum, conexões, cargos e uma nota só sua.

  11. Mensagens salvas, com anotação

    Ctrl+Shift+S: favoritos que ficam só no seu computador. Nada vai para o Discord.

  12. Alertas e filtros

    Palavras de alerta contam como menção, o filtro recolhe mensagens, “ignorar” esconde alguém sem bloquear e o modo foco silencia tudo menos DMs e menções. Tudo local.

  13. E o resto

    Respostas, edição, reações, botão direito em tudo, seleção de texto entre mensagens, imagens e GIFs, pastas de servidores, abas de canal, várias contas, rascunho por canal, proxy e Tor, inglês e português, teclas de vim opcionais. Tour completo →

}

plugins sandbox=#true {

Lua, numa jaula.

Coloque um .lua em ~/.config/sigmacord/plugins/ para somar painéis, entradas no botão direito, notas embaixo das mensagens, comandos e atalhos, sem recompilar nada. Anti-golpe, radar de CVE, cartões do GitHub, o que perdi, tradução, lembretes, destaques, links limpos, e links e arquivos vêm com o app.

lua
-- @name CVE notes
-- @capabilities messages, decorate, http
-- @hosts cveawg.mitre.org
sigma.on("message", function(msg)
  local id = msg.content:upper():match("CVE%-%d+%-%d+")
  if not id then return end
  sigma.http.get("https://cveawg.mitre.org/api/cve/" .. id, function(res)
    local cve = res.ok and sigma.json.decode(res.body)
    local cna = cve and cve.containers and cve.containers.cna
    if cna and cna.title then
      sigma.decorate(msg.id, { note = id .. ": " .. cna.title })
    end
  end)
end, { contains = { "cve-" } })
  • Numa thread só deles. Um plugin lento não engasga a interface. Sem plugin ligado, a thread nem existe.
  • Sem arquivos, sem processos, sem sockets. io, os.execute, require, load e debug simplesmente não existem. A única rede é HTTPS para hosts que você aprova um a um, sem o seu token nem cookies.
  • Cerca de 5 milhões de instruções por chamada. Um while true do end é parado e não congela o app. O pcall não segura esse erro.
  • 8 MB por plugin. Cada um roda num Lua separado. Depois de 10 erros, ele é parado.
  • sigma.send só funciona a partir de um gesto seu. Responder sozinho transformaria a conta num self-bot, então isso é bloqueado de propósito. API de plugins →
SigmaCord

Os dados são da demonstração, mas as notas de CVE e do GitHub são respostas de verdade desses serviços. Nada sai antes de você aprovar o host no cartão do plugin.

  • Anti-golpe. Links de Nitro grátis, dlscord-nitro.ru, endereços em outro alfabeto, um link que mostra um site e abre outro: tudo em vermelho. Roda no seu computador, sem rede.
  • Radar de CVE. Alguém escreve CVE-2021-44228, e a severidade, a nota CVSS e um resumo aparecem embaixo da mensagem, vindos do registro oficial.
  • Cartões do GitHub. dono/repo#123 e links do GitHub ganham título, estado e estrelas. Um repositório renomeado aparece com o nome atual.
  • O que perdi. /perdi resume as não lidas: quem falou, quem chamou você, que perguntas ficaram sem resposta, links e arquivos, com um clique até cada um.

metrics budget=50 {

Sem mágica. Dez decisões chatas.

  1. Dorme quando nada acontece. O laço principal espera em SDL_WaitEvent. Rede, inotify e relógio acordam o app com eventos. Sem animação, sem redesenho.
  2. Nada de navegador. Tudo é desenhado com o ImDrawList do Dear ImGui sobre o SDL_Renderer.
  3. Fontes mapeadas, não copiadas. Cada arquivo de fonte é um mmap usado por todos os pesos, então só as páginas lidas ficam na RAM.
  4. Só o driver de vídeo necessário. Em máquinas só com NVIDIA, o glvnd também carregaria o Mesa e o LLVM à toa. O app detecta e evita.
  5. Markdown interpretado uma vez. Quando a mensagem chega. Depois, a interface só faz layout dos trechos, com cache de altura por largura.
  6. Lista virtualizada. Busca binária pelo primeiro item visível e desenha só o que está na tela.
  7. Memória com teto. 1.500 mensagens por canal e 3.000 no total. Conversas esquecidas são descarregadas, e o cache de imagens tem um teto fixo de 64 MB.
  8. fontconfig liberado. Depois de resolver as fontes: FcFini e malloc_trim.
  9. Sem cursor piscando. Um cursor piscando manteria a CPU acordada à toa.
  10. As coisas nascem quando você pede. A thread de voz na primeira call, o FFmpeg no primeiro vídeo. Sem plugin ligado, não há thread de plugins nem Lua, e nada se gasta por mensagem, tecla ou quadro.
interface → Action → app → Command → gateway → Event → Store → interface

A interface nunca muda dados direto. Ela só lê o Store e pede ações, e é por isso que trocar o gateway de demonstração pelo real não toca na interface. Arquitetura →

Linux x86_64

Baixar para Linux ↓

curl -fsSL https://raw.githubusercontent.com/sambukuper/SigmaCord/main/install.sh | sh
