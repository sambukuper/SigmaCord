channel-list variant=tree {

It speaks the real gateway. It's a real client.

  1. Split view

    Up to three conversations side by side, each with its own history and scroll position. The composer follows the focused pane.

  2. Threads and forums

    Threads nest under their channel and open like any conversation, with tabs, drafts and search. Forums show their posts instead of a chat, with tags and “New Post”.

  3. Emoji and autocomplete

    Custom emoji and stickers show as images, animated too. The picker has the full Unicode list and your servers' emoji. In the text box, @, #, :ab and / open a list.

  4. Read state, in sync

    Unreads and mentions match Discord when you open the app, and reading on another device clears them here. Channels open at the first unread. Pins live behind the pin icon, and Discord links open in the app.

  5. Inbox

    Ctrl+I: unread DMs and mentions from every server, by channel, with previews and “mark all as read”.

  6. Offline search

    Ctrl+F searches memory and the local cache on every keystroke, no internet needed. Filters: from:, in:, has:link, has:image, has:file.

  7. Command palette

    Ctrl+K: fuzzy search for channels, DMs, servers, themes, status and every toggle. This page has one too. Try it.

  8. Video in the chat

    Attachments and direct links play in place through your system's FFmpeg, loaded only on the first play. Up to 480p and about 30 fps. Without FFmpeg, the video opens in your browser.

  9. Code that reads like code

    Discord markdown, parsed once when the message arrives. Code blocks get highlighting in your theme's colors and a copy button, and a live preview sits above the composer.

  10. Full profiles

    Banner, bio, activity, mutual friends and servers, connections, roles and a private note.

  11. Saved messages, with notes

    Ctrl+Shift+S: bookmarks that live only on your computer. Nothing goes to Discord.

  12. Alerts and filters

    Alert words count as mentions, a word filter collapses messages, “ignore” hides someone without blocking them, and focus mode quiets everything but DMs and mentions. All local.

  13. And the rest

    Replies, edits, reactions, right-click menus everywhere, multi-message text selection, images and GIFs, server folders, channel tabs, multiple accounts, drafts per channel, proxy and Tor support, English and Portuguese, optional vim keys. Full tour →

}

plugins sandbox=#true {

Lua, in a cage.

Drop a .lua file in ~/.config/sigmacord/plugins/ to add panels, right-click entries, notes under messages, commands and keybinds, without recompiling anything. Scam guard, CVE radar, GitHub cards, what did I miss, translate, reminders, highlights, clean links, and links and files come with the app.

lua
-- @name CVE notes
-- @capabilities messages, decorate, http
-- @hosts cveawg.mitre.org
sigma.on("message", function(msg)
  local id = msg.content:upper():match("CVE%-%d+%-%d+")
  if not id then return end
  sigma.http.get("https://cveawg.mitre.org/api/cve/" .. id, function(res)
    local cve = res.ok and sigma.json.decode(res.body)
    local cna = cve and cve.containers and cve.containers.cna
    if cna and cna.title then
      sigma.decorate(msg.id, { note = id .. ": " .. cna.title })
    end
  end)
end, { contains = { "cve-" } })
  • On a thread of their own. A slow plugin can't make the interface stutter. With no plugin on, the thread doesn't even exist.
  • No files, no processes, no sockets. io, os.execute, require, load and debug simply don't exist. The only network is HTTPS to hosts you approve one by one, without your token or cookies.
  • About 5 million instructions per call. A while true do end gets stopped and doesn't freeze the app. pcall can't catch that.
  • 8 MB per plugin. Each one runs in its own Lua state. After 10 errors, it's stopped.
  • sigma.send only works from your own gesture. Automatic replies would make your account a self-bot, so they're blocked by design. Plugin API →
SigmaCord

Demo data, but the CVE and GitHub notes are real answers from those services. Nothing goes out until you approve the host on the plugin's card.

  • Scam guard. Free Nitro links, dlscord-nitro.ru, addresses in another alphabet, a link that shows one site and opens another: marked in red. It runs on your computer, with no network.
  • CVE radar. Someone writes CVE-2021-44228, and the severity, the CVSS score and a summary appear under the message, from the official record.
  • GitHub cards. owner/repo#123 and GitHub links get the title, the state and the stars. A renamed repository shows its current name.
  • What did I miss. /missed sums up the unread messages: who talked, who called you, which questions nobody answered, links and files, with a click to each one.

metrics budget=50 {

No magic. Ten boring decisions.

  1. It sleeps when nothing happens. The main loop waits in SDL_WaitEvent. Network, inotify and the clock wake it up with events. No animation, no redraw.
  2. No browser. Everything is drawn with Dear ImGui's ImDrawList on top of SDL_Renderer.
  3. Fonts are mapped, not copied. Each font file is one mmap shared by every weight, so only the pages read stay in RAM.
  4. Only the video driver it needs. On NVIDIA-only machines, glvnd would also load Mesa and LLVM for nothing. The app detects that and avoids it.
  5. Markdown is parsed once. When the message arrives. After that, the UI only lays out spans, with a height cache per width.
  6. A virtualized list. Binary search for the first visible item, then draw only what's on screen.
  7. Memory has ceilings. 1,500 messages per channel and 3,000 in total. Forgotten conversations get unloaded, and the image cache has a fixed 64 MB budget.
  8. fontconfig gets freed. After fonts are resolved: FcFini, then malloc_trim.
  9. No blinking cursor. A blinking cursor would keep the CPU awake for no good reason.
  10. Things start when you ask. The voice thread on your first call, FFmpeg on your first video. With no plugin on, there's no plugin thread and no Lua, and nothing is spent per message, key or frame.
UI → Action → app → Command → gateway → Event → Store → UI

The UI never changes data directly. It only reads the Store and asks for actions, which is why swapping the demo gateway for the real one doesn't touch the UI. Architecture →

download variant=latest {

Get it. Run it.

No account needed to look around: the demo mode connects to nothing. After that it updates itself, and every update is signed.

Linux x86_64

Download for Linux ↓

A single file that runs on distros from about 2022 onward (glibc 2.34). Before each release it's opened on Ubuntu, Debian, Fedora, openSUSE and Arch. Make it executable with chmod +x and run it.

Or install it, listing any library that's missing:

curl -fsSL https://raw.githubusercontent.com/sambukuper/SigmaCord/main/install.sh | sh

Windows 10 / 11, x64

Download for Windows ↓

Unzip it and open sigmacord.exe. The program isn't code-signed yet, so Windows may warn you the first time.

Or install it for your user, in PowerShell:

irm https://raw.githubusercontent.com/sambukuper/SigmaCord/main/install.ps1 | iex
