#Command line

bash
sigmacord [options]
OptionWhat it does
--theme NAMEstarts with this theme
--list-themeslists the built-in themes and exits
--mode MODEclaro (or light) or escuro, ignoring your settings
--lang LANGpt or en, ignoring your settings
--demouses the demo data even with a token
--loginshows the sign-in screen, ignoring the saved token
--settingsopens straight into settings
--no-liveturns off the demo mode's automatic messages
--shot FILE.pngsaves a screenshot once the screen settles, then exits
--statsshows the time to first frame
--qaruns the automatic UI test, with screenshots in qa-out/
--voice-test GUILD CHANNELjoins a voice channel for 25 s, always muted (needs SIGMACORD_TOKEN)
--helpshows the usage text

#Environment variables

VariableWhat it does
SIGMACORD_TOKENthe account token (see Connect your account)
SIGMACORD_RENDERERpicks the SDL render backend: opengl, vulkan, gpu or software
SIGMACORD_HIDDENopens with a hidden window. The app draws nothing while hidden, so memory reads much lower than with a real window
SIGMACORD_BENCHredraws nonstop, to measure the cost of a frame
SIGMACORD_VOICE_DEBUGprints what happens in a call (opcodes, close codes, DAVE). It never prints tokens or keys
SIGMACORD_DEBUG_MEDIAlogs why an image failed to load
SIGMACORD_NO_FFMPEGpretends FFmpeg isn't installed
SIGMACORD_EGL_ALLturns off the trick that skips unneeded EGL drivers
SIGMACORD_SCENEsets up a scene for documentation screenshots
SIGMACORD_RECORD, SIGMACORD_RECORD_FRAMESrecords the sign-in screen as frames in a folder
SIGMACORD_FLOODsends N presence changes per second in demo mode (load test)

XDG_CONFIG_HOME and XDG_CACHE_HOME are respected, and they're handy for running with a clean configuration.
